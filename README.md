# Getting Started with Create React App

### After Cloning You have to Create a `patient-management-frontend/.env` file.
### For Using this project locally add this in the env file:
`
REACT_APP_API_BASE_URL=http://localhost:8080/api
REACT_APP_WS_URL=http://localhost:8080/ws
`
### If the Project is not running Locally then Write the respective URLS in ENV.

### To Start The Frontend Run:
### 1. Open the Directory `.patient-management-frontend`
### 2. `npm install`
### 3. `npm start`
